# PinPoint AI 캐디 (PWA)

기획서 「아마추어 골퍼 필드 페인포인트 정밀 분석 & 올인원 AI 캐디 앱 기획」을 구현한 오프라인 우선 모바일 웹앱입니다.

**배포 주소: https://funwings77-sudo.github.io/golf/** (GitHub Pages, `main` 브랜치에 푸시하면 자동 재배포)
휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

**Android 앱 다운로드 페이지: https://funwings77-sudo.github.io/golf/download.html** (APK 직접: [pinpoint-caddie.apk](https://funwings77-sudo.github.io/golf/pinpoint-caddie.apk)) (디버그 서명, 설치 시 "출처를 알 수 없는 앱" 허용 필요 · 재빌드+업로드: `npm run release:apk`)

## 실행
```
npm start          # http://localhost:8080
npm test           # 엔진·추천·AR 18개 + 관리자 8개 + 코스 DB·OSM·그린 검증 5개
```
휴대폰의 GPS·나침반·기울기 센서·카메라는 **HTTPS**에서만 동작합니다. 폴더를 그대로 GitHub Pages / Netlify / Cloudflare Pages 등에 올리고 휴대폰에서 열어 "홈 화면에 추가"하세요. 실내 테스트는 설정 → GPS 시뮬레이션 + 홈 → 데모 코스.

## 쉬운 플레이 (기본 화면, 초등학생도 쓰는 흐름)
디자인 v2 (`css/theme.css`): 밝은 세이지 바탕 + 라임 포인트 + 검은 알약 버튼(→ 동그라미), 큰 굵은 질문 제목·등고선 무늬, 위성 사진 코스 썸네일·사진 큰 카드, 지도 위 유리 칩(바람·깃발 높이·친 뒤 남는 거리), 떠 있는 하단 탭, 검은 통계 카드(좌우 결과 막대). 다크 모드 지원.
원칙: **한 화면 = 지금 할 일 한 줄(👉) + 큰 버튼 하나 + 보조 버튼 둘.** 배울 것 없이 안내 줄만 따라 하면 됩니다.
① **골프장 누르기 → 바로 1번 홀** (📍 지금 있는 골프장 사진 카드 · 목록 하나 · 코스 정보를 받고 기본 코스 순서로 시작 · 코스·동반자는 [더보기 → 코스·친구 바꾸기]) → ② **홀 화면**(앱 머리줄·하단 탭을 숨기고 메뉴는 [🧰 더보기] 안에 · 쉬운 화면 지도는 나·떨어질 곳·깃발 선만, 클럽 안내는 한 문장)
- **그린 좌표가 없는 실제 골프장**: 첫 [쳤어요] 자리를 티로, 그린을 모르는 홀에서 점수를 저장할 때 선 곳(티에서 충분히 먼 곳)을 그린으로 저절로 배움 → 다음부터 정확한 거리. 그 전에는 '홀 길이 − 티에서 온 거리'로 어림 거리, 그린을 몰라도 [쳤어요]→[찾았어요]로 날아간 거리 기록
- 큰 버튼이 상황 따라 바뀜: **🏌️ 쳤어요** → **✅ 공 찾았어요** → 그린 위 **⛳ 홀에 넣었어요**(점수 입력, 마지막 홀이면 🏁 라운드 끝) · 그린 좌표가 없는 홀은 **⛳ 여기가 그린이에요**(그린 위에서 누르면 GPS 3초 평균으로 저장)
- 점수 입력 기본값 = [쳤어요] 누른 횟수 + 퍼트 2 · 거리가 많이 틀릴 수 있을 때만 경고 한 줄
- **친 공 분석**: [쳤어요] 직후 예상 공 속도·발사 각도·높이·비행 시간 → [찾았어요] 때 **측정**(GPS 총거리 ±오차, 좌우 방향 °·m)과 **계산**(잰 거리·바람·공기밀도로 3자유도 탄도 모델을 거꾸로 풀어 공 속도·헤드 속도·캐리·런·최고 높이·비행 시간·착지 각도/속도, 발사각 ±3°·스핀 ±15% 범위) + 옆에서 본 비행 곡선. 휴대폰은 공 속도·발사각·스핀을 직접 잴 수 없어 계산값으로 구분 표시 (`physics/shotfit.js`, `views/shotviz.js`)
- **📟 론치 모니터 수치 입력** (`views/lmform.js`): 결과 카드·지난 샷에 공 속도(필수)·발사 각도·백스핀·헤드 속도·캐리·총거리·좌우 방향/거리·최고 높이를 옮겨 적기(km/h·mph·m/s, m·yd, 범위 확인으로 단위 착오 잡기). 넣은 값은 '모니터'로 표시하고 빈칸만 물리식으로 계산, GPS 거리가 있으면 GPS 우선, 물리식 캐리와 차이 % · 연습장/스크린용 '모니터 샷 추가'(GPS 없이)
- **📂 론치 모니터 기록 파일(CSV) 불러오기** (`core/lmcsv.js`, `views/lmimport.js`): 가민 R10·랩소도·플라이트스코프·트랙맨·국산 기기(한글 열 이름)에서 흔한 열 이름·단위 표기([mph]·(yds)·(m/s)·ft)·단위 줄·앞쪽 정보 줄·세미콜론/소수점 쉼표·"5.2 L"·EUC-KR을 알아봄 → 미리보기에서 열 연결·기본 단위·클럽 이름 연결·좌우 뒤집기를 고친 뒤 불러오기 (퍼터 빼기, 같은 샷은 다시 안 넣음)
- **📈 내 샷 기록** (`views/shots.js`): 클럽별 평균·최장 거리, 공 속도, 높이, 방향 평균·좌우 퍼짐, 위에서 본 탄착점, 샷별 결과 카드·잘못 잰 샷 지우기 (힘 덜 준 샷은 평균·비거리 학습에서 제외)
- 공(또는 내 위치)에서 **깃발까지 거리**(앞·뒤), **추천 클럽 · 힘 %(시계 스윙 크기) · 방향 각도(깃발 기준 좌우 0.1°, 방위)**, 공이 떨어질 곳, 추천 길(노란 선)
- **🏌️ 쳤어요** → 친 공 위치 예측(파티클) → **내 공까지 거리·방향 화살표**(나침반 기준) → **✅ 찾았어요**(실제 비거리 학습)
- **📍 내 공 여기!**: 지도에서 공 위치를 찍으면 공 기준으로 다시 계산
- 보기 전환: **2D**(위성 지도·확대) · **3D**(지형 고도 타일로 기울여 보기·회전·확대) · **4D**(3D + 시간: 공 비행 재생·시간 막대·홀 플라이오버) · **AR**(카메라 위에 깃발·추천 길·떨어질 곳·내 공·해저드, 회전행렬 투영 + 1탭 방위 보정)
- 관련 코드: `views/play.js`, `physics/advice.js`, `views/view3d.js`(MapLibre), `views/arview.js` + `core/arproj.js`

## 안정성 · 데이터 보호
- **저장 실패를 숨기지 않음**: 저장 공간이 차면 알림 + 백업·정리 안내, 라운드 끝은 기록을 먼저 저장하고 성공해야 진행 중 라운드를 지움, 깨진 저장값은 `pinpoint.corrupt.*`에 보관 (`core/state.js`)
- **전체 백업·복원**: 설정 → 💾 내 기록 지키기 (라운드·샷은 합치기, 앱에서는 휴대폰 공유 창으로 파일 저장 `core/files.js` + @capacitor/filesystem·share) · 저장 공간 막대
- **그린 높이 격자 압축 저장**: 16비트(0.1mm) + base64로 약 6배 작게 (메모리에서는 숫자 배열 그대로)
- 오류 기록(`pinpoint.errlog`) · 화면 오류 시 다시 시도 · 안드로이드 뒤로 가기(창 닫기 → 이전 화면 → 두 번 눌러 나가기, @capacitor/app) · 앱으로 돌아오면 화면 켜짐·위치 다시 찾기 · 위치가 꺼져 있을 때 켜는 방법 안내
- 앱(APK)에서도 미리 받은 위성 지도 사용(지도 칸이 Cache Storage에서 직접 꺼냄) · 첫 실행에 인터넷이 약해도 골프장 목록(앱에 함께 넣음) · 서비스 워커는 3초 안에 안 오면 저장본

## 코스 DB 적용 (KGBA 회원사 209곳)
```
node scripts/import-kgba.mjs <golf_courses.sql> [--geocode]
```
- `data/clubs.json`: 전국 209곳 골프장 목록(지역·홀·운영·전화·주소·홈페이지·요금·잔디·수집 상태·대략 위치) → 앱 '전국 골프장 찾기'(이름·지역 검색, 가까운 순)
- `data/courses/kgba-<id>.json` + `data/catalog.json`: 홀 데이터가 있는 19곳의 공식 코스(파·핸디캡·백/블루/화이트/레드 거리·공략 메모, 9·18홀 코스 묶음)
- DB에 GPS 좌표가 없어 티·그린 위치는 비어 있습니다. 앱에서 그린을 한 번 눌러 지정하거나(이 기기에 저장, 코스 업데이트 후에도 유지), 관리자 편집기에서 지정·발행하면 모든 사용자에게 적용됩니다. 관리자가 지정한 위치·그린맵은 DB를 다시 가져와도 보존됩니다.
- `--geocode`: 주소·이름으로 대략 위치를 구해 `scripts/kgba-geo.json`에 캐시(OSM Nominatim, 1초 1회). OSM에는 국내 골프장의 홀 단위 데이터가 거의 없어 홀 좌표 자동 추출은 하지 않습니다.

## 한계 (웹 플랫폼)
- 브라우저는 LiDAR·ARCore Depth에 접근 불가 → 기획서의 Tier 2~3 방식(기울기 센서 + 사전 그린맵, 카메라 지면 투영 1탭 보정)으로 구현. 결과마다 신뢰도 표시.
- 실제 골프장 그린맵 원천 데이터는 측량사 제휴 영역입니다. 관리자 페이지가 측량 파일(격자·측량점)을 받아 발행하는 경로를 제공합니다. 데모 코스·그린은 가상 데이터.
