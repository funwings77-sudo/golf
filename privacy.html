개인정보처리방침

PinPoint AI 캐디 (Android 앱 · 웹앱) · 시행일 2026년 11월 18일

요약

  • 회원가입·로그인이 없습니다. 이름, 전화번호, 이메일을 받지 않습니다.
  • 라운드 기록·코스·설정은 내 휴대폰 안에만 저장되고, 개발자 서버로 보내지 않습니다.
  • 광고, 분석(트래킹) 도구, 개인정보 판매가 없습니다.

휴대폰 권한과 쓰는 곳

권한쓰는 곳
위치 (앱 사용 중에만)깃발·그린·해저드까지 거리 계산, 가까운 골프장 찾기, 친 공 위치 안내, 그 지점 날씨·바람. 위치 기록은 휴대폰 안에만 저장됩니다.
카메라AR 거리 측정·그린 리딩, 깃대 거리 재기, 공 찾기. 영상은 휴대폰 안에서만 처리하며 저장·전송하지 않습니다(아래 AI 캐디 사진 기능을 직접 쓰는 경우 제외).
동작·방향 센서경사 측정, 나침반 방향, 걸음 수, 스윙 감지.
진동 · 화면 켜두기알림 진동, 라운드 중 화면이 꺼지지 않게 유지.

서비스보내는 정보 · 목적
Open-Meteo (날씨)현재 위치의 대략적인 좌표 → 기온·바람·낙뢰 위험 정보
지도 타일 (Esri ArcGIS, AWS 지형 타일)보고 있는 지도 영역 → 위성 사진·고도 타일
GitHub Pages (이 사이트)골프장 코스 데이터·공지·오늘의 핀·새 버전 정보를 받음 (보내는 개인정보 없음)
Google Gemini API (선택)설정에서 본인의 Gemini API 키를 직접 넣고 AI 캐디를 쓸 때만, 질문 내용과 직접 첨부한 사진·음성, 코스 정보(좌표 제외)를 Google에 보냅니다. 키는 휴대폰에만 저장됩니다. Google의 처리는 Google 개인정보처리방침을 따릅니다.

골프장 제출용 라운드 리포트는 사용자가 직접 내보낼 때만 파일로 만들어지고, 사용자가 고른 곳으로만 전달됩니다. 내 스코어, 홀 도착 시각, 분실구 지점(약 1m 단위)만 들어 있으며 이름·동반자·이동 경로·기기 정보는 넣지 않습니다.

보관과 삭제

  • 모든 기록은 휴대폰의 앱 저장공간에 있습니다. 앱을 삭제하거나 휴대폰 설정 → 앱 → PinPoint 캐디 → 저장공간 → 데이터 삭제를 누르면 모두 지워집니다.
  • 개발자는 사용자의 기록을 받지 않으므로 따로 보관하거나 삭제 요청을 처리할 데이터가 없습니다.
